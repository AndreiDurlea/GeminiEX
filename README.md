Makes the Google Gemini (`gemini.google.com`) chatbox use the full width of your screen, instead of leaving empty white space on the sides.

## Features
- Dynamic widths for user query bubbles
- 100% responsive and cross-browser compatible
- Lightweight vanilla JS/CSS architecture

## Installation

### Developer Mode Installation
1. Clone this repository or download the `.zip` file from the [Releases](#) tab.
2. If downloaded as `.zip`, extract the files to a local folder.
3. Depending on your browser:
    - **Chrome / Edge**: Open `chrome://extensions` or `edge://extensions`, enable **Developer mode**, and click **Load unpacked**. Select the `src` folder.
    - **Firefox**: Open `about:debugging`, click **This Firefox**, and load the extension temporarily by selecting the `src/manifest.json` file.
