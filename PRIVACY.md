# Privacy Policy

**GeminiEX** is a browser extension that modifies the visual layout of [gemini.google.com](https://gemini.google.com) to make the chat interface use the full width of your screen.

## Data Collection

GeminiEX does **not** collect, store, transmit, or share any data of any kind. This includes but is not limited to:

- Personal information
- Browsing history
- Usage analytics or telemetry
- Cookies or tracking identifiers
- Chat content, prompts, or responses

## Permissions

GeminiEX requests only the minimum permissions needed to function:

- **Host permission** (`gemini.google.com`): Required to inject CSS and JavaScript that adjust the page layout. The extension operates exclusively on this domain and does not interact with any other website.

## Network Requests

GeminiEX makes **zero** network requests. It does not communicate with any external server, API, or third-party service.

## Third-Party Services

GeminiEX does not use any third-party services, SDKs, analytics platforms, or advertising frameworks.

## Open Source

GeminiEX is fully open source. You can inspect the complete source code at any time on [GitHub](https://github.com/AndreiDurlea/GeminiEX).

## Changes to This Policy

If this policy is ever updated, the changes will be reflected in this file and documented in the repository's commit history.

## Contact

If you have any questions or concerns about this privacy policy, please open an issue on the [GitHub repository](https://github.com/AndreiDurlea/GeminiEX/issues).
